# Product

## Register

product

## Users

El producto tiene dos grupos principales: clientes de AIQ que consultan información técnica y comercial mediante un asistente, y administradores internos que gestionan accesos, conocimiento y seguimiento de uso.

## Product Purpose

Centralizar el contenido público, la zona privada de clientes y el asistente de AIQ. El historial y la base de conocimiento deben ser persistentes para conservar continuidad, trazabilidad y contexto operativo, incluso cuando un acceso se deshabilita o un cliente oculta una conversación.

## Brand Personality

Técnica, confiable y directa. La interfaz debe transmitir control y claridad sin perder el carácter cercano de AIQ.

## Anti-references

Evitar dashboards genéricos de tarjetas decorativas, visualizaciones sin escala o contexto, interfaces recargadas y patrones que oculten información operativa importante.

## Design Principles

- Preservar el contexto antes que simplificar los datos.
- Mostrar primero el estado y la actividad que requieren atención.
- Mantener acciones y navegación familiares para reducir errores.
- Distinguir claramente lo visible para el cliente de lo conservado para administración.
- Diseñar para lectura rápida en escritorio y consulta usable en pantallas pequeñas.

## Accessibility & Inclusion

Mantener contraste WCAG AA, foco visible, estructura semántica, estados que no dependan solo del color y compatibilidad con reducción de movimiento.
